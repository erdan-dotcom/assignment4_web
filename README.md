# Assignment 4: Forms and Validation

## Description
This project demonstrates the creation and styling of HTML forms along with validation. It covers:
1. Basic HTML5 forms with built-in browser validation.
2. Form styling using Bootstrap 5 classes.
3. Custom Bootstrap validation feedback (success/error messages).
4. An advanced responsive Registration form using Bootstrap Grid system.

## Project Structure
- `index.html`: Main page with a navigation menu.
- `basic.html`: Part 1 - Basic HTML contact form.
- `bootstrap.html`: Part 2 & 3 - Styled form with Bootstrap validation.
- `register.html`: Part 4 - Advanced multi-input registration form.
- `styles.css`: Custom styling for layout enhancements.

## How to use
Open `index.html` in any modern browser to navigate between the tasks. Try submitting empty forms to see the validation in action!
